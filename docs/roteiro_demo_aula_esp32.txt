============================================================
11. DNS: ESTADO ATUAL
============================================================
O NAT já funciona no nível IP.
O DNS automático via DHCP ainda está em ajuste.

Se precisar provar navegação por domínio:
sudo resolvectl dns wlp3s0 1.1.1.1 8.8.8.8
sudo resolvectl domain wlp3s0 "~."
ping -c 3 google.com

Fala sugerida:
"Com DNS manual, google.com resolve e responde. Isso mostra que o NAT funciona; a pendência é automatizar a entrega de DNS via DHCP."

Para desfazer o DNS manual:
sudo resolvectl revert wlp3s0
sudo systemctl restart NetworkManager
